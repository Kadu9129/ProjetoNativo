Este APK contém a versão local e offline-first do MapPin, com CRUD de lugares persistido em SQLite, sem backend e sem chave de API. O mapa online usa tiles do OpenStreetMap; quando não há internet, os dados e marcadores continuam disponíveis na grade local.

O APK foi validado com `apksigner`, instalado e iniciado com sucesso em um emulador Android. Para apresentação e avaliação, a assinatura de desenvolvimento é suficiente. Para publicação em uma loja, gere uma nova versão com uma chave de produção mantida em local seguro.
